
# AI-Based Image Classification Using TensorFlow

## Project Description

This project is an Artificial Intelligence application
that identifies objects in images using Deep Learning.

It uses a Convolutional Neural Network (CNN) built
with TensorFlow and Keras.

## Technologies Used

- Python
- TensorFlow
- Keras
- NumPy
- Pillow
- Flask
- HTML
- CSS

## Dataset

CIFAR-10 Dataset

The dataset contains 60,000 images in 10 categories:

1. Airplane
2. Automobile
3. Bird
4. Cat
5. Deer
6. Dog
7. Frog
8. Horse
9. Ship
10. Truck

## Features

- Train an AI image classification model
- Upload images
- Predict image categories
- Display prediction confidence
- Display top 3 predictions
- Web-based user interface

## Installation

Install the required libraries:

pip install -r requirements.txt

## Train the Model

python train_model.py

## Run Prediction

python predict.py cat.jpg

## Run Web Application

python app.py

Open your browser:

http://127.0.0.1:5000

## Expected Output

The application displays:

- Uploaded image
- Predicted object category
- Confidence percentage
- Top 3 predictions
